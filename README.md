# Griseofulvin-Model
Whole-body PBPK model of griseofulvin.

## Repository files
This repository contains:

- a PK-Sim snapshot (*.json) file of the current whole-body PBPK model of griseofulvin
- static content (e.g. text blocks, *.md files) as inputs for an evaluation plan
- an evaluation plan (evaluation-plan.json) to create an evaluation report using the snapshot and static text blocks to display the performance of the model
  
The model was developed using data from 2 clinical studies (dosing range IV 99-142 mg and Oral administration after 500 mg). The PK-Sim snapshot file contains simulations and the observed data of all clinical studies used for model development and evaluation.
